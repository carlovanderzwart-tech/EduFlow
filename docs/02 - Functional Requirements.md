# Functional Requirements

## Doel

EduFlow ondersteunt onderwijsprofessionals bij administratieve, organisatorische en documenterende werkzaamheden.

Iedere functionaliteit moet bijdragen aan tijdsbesparing, eenvoud en een prettige gebruikerservaring.

---

# Dashboard

## Functionaliteiten

De gebruiker kan:

- recente documenten bekijken;
- recente AI-gesprekken openen;
- snelle acties uitvoeren;
- agenda-items bekijken;
- openstaande taken zien;
- direct navigeren naar iedere module.

---

# Documentatie

## Functionaliteiten

De gebruiker kan:

- een nieuwe documentatie maken;
- foto's uploaden;
- observaties toevoegen;
- AI een documentatie laten schrijven;
- bestaande documentaties openen;
- documentaties aanpassen;
- documenten dupliceren;
- documenten exporteren naar Word;
- documenten exporteren naar PDF;
- documenten verwijderen.

### AI ondersteunt

- Reggio Emilia schrijfstijl;
- observaties structureren;
- passende titels genereren;
- leerprocessen beschrijven;
- vervolgactiviteiten voorstellen;
- nieuwsbriefteksten genereren;
- rapportteksten genereren.

---

# AI Chat

De AI Chat is de centrale assistent van EduFlow.

Vanuit de chat kunnen opdrachten worden uitgevoerd voor alle modules.

Voorbeelden:

- Schrijf een oudermail.
- Maak een documentatie.
- Plan een afspraak.
- Vat deze mail samen.
- Maak een nieuwsbrief.

# Niet-functionele eisen

De software moet:

- snel reageren;
- eenvoudig te gebruiken zijn;
- modulair opgebouwd zijn;
- uitbreidbaar zijn;
- veilig omgaan met gegevens;
- platformonafhankelijk werken binnen moderne browsers.

---

# Ontwerpregel

Iedere nieuwe functionaliteit moet bijdragen aan minimaal één van de volgende doelen:

- tijd besparen;
- minder klikken;
- betere kwaliteit van documenten;
- automatiseren van repetitieve werkzaamheden;
- centraliseren van bestaande workflows.
