# Hooks

Gedeelde React hooks die door meer dan één module worden gebruikt (bijvoorbeeld
een hook rond `StorageService` of rond het opslagquotum). Hooks die maar bij één
module horen, staan in `src/modules/<module>/hooks/`.

Leeg in Sprint 1 — er is nog geen gedeelde hook nodig zolang er geen opslag of
AI-laag bestaat.
