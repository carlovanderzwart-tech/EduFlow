# Module: Documentatie

Zie `docs/02 - Functional Requirements.md` (Documentatie) en
`docs/04 - Product Blueprint.md` (Scherm 2 en 3).

Prioriteit 1 (zie doc 02, *Prioriteiten*) — de belangrijkste module van
EduFlow. In Sprint 1 bevat deze module alleen de route en een
placeholder-scherm. Overzicht, schrijf-/gespreksmodus, templates, export en
privacyafscherming volgen in latere sprints.

Zodra deze module functionaliteit krijgt, volgt hij dezelfde indeling als de
overige modules: `components/`, `hooks/`, `services/`, `types/`. Die submappen
worden pas aangemaakt zodra ze een bestand bevatten.
