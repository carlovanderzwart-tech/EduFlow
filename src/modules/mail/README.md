# Module: Mail

Zie `docs/02 - Functional Requirements.md` (Mail) en
`docs/04 - Product Blueprint.md` (Scherm 4 — Mail).

Prioriteit 2 (zie doc 02, *Prioriteiten*). In Sprint 1 bevat deze module alleen

concepten.

overige modules: `components/`, `hooks/`, `services/`, `types/`. Die submappen
worden pas aangemaakt zodra ze een bestand bevatten.
