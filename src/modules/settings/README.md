# Module: Instellingen

Zie `docs/02 - Functional Requirements.md` (Instellingen) en
`docs/04 - Product Blueprint.md` (Scherm 6 — Instellingen).

Wordt gebouwd op het moment dat een module de betreffende instelling nodig
heeft, niet als apart project (zie doc 02, *Prioriteiten*). In Sprint 1 bevat
deze module alleen de route en een placeholder-scherm.

Zodra deze module functionaliteit krijgt, volgt hij dezelfde indeling als de
overige modules: `components/`, `hooks/`, `services/`, `types/`. Die submappen
worden pas aangemaakt zodra ze een bestand bevatten.
