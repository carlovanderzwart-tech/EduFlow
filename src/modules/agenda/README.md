# Module: Agenda

Zie `docs/02 - Functional Requirements.md` (Agenda) en
`docs/04 - Product Blueprint.md` (Scherm 5 — Agenda).

Prioriteit 3 (zie doc 02, *Prioriteiten*). In Sprint 1 bevat deze module alleen
de route en een placeholder-scherm — geen schoolvakanties, geen eigen
afspraken en geen maand-/jaarweergave.

Zodra deze module functionaliteit krijgt, volgt hij dezelfde indeling als de
overige modules: `components/`, `hooks/`, `services/`, `types/`. Die submappen
worden pas aangemaakt zodra ze een bestand bevatten.
